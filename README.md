# Registration & Contact Forms
## Overview
This project contains responsive, user-friendly web forms built using HTML5, Bootstrap 5, and JavaScript.

Live: https://glore81.github.io/web-dev4
## Features
* **Responsive Design:** Utilizes Bootstrap Grid (`row`, `col-md-6`) to adapt to different screen sizes.
* **Client-Side Validation:** 
  * HTML5 validation attributes (`required`, `minlength="8"`, `type="email"`).
  * Custom Bootstrap validation feedback (green/red borders and text).
* **Form Components:** Includes text inputs, email inputs, passwords, select dropdowns, grouped radio buttons, and checkboxes.

## Technologies Used
* HTML5
* CSS3
* JavaScript

## How to Run
1. Clone the repository or download the project files.
2. Ensure `index.html`, `style.css`, and `script.js` are located in the same directory.
3. Open `index.html` in any modern web browser. No local server or build tools are required.
